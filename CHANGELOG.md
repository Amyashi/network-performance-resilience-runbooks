# Changelog

## 1.0.0 - 2026-07-30

- Published separate Windows 11 Pro, Windows 11 Home, and macOS Apple-silicon
  runbooks.
- Preserved Amy's bounded 2/2 Gbps and approximately 3.8-3.9 Gbps simultaneous
  aggregate evidence.
- Documented direct-host and eero-wide failover through T-Mobile Home Backup
  Internet, including the shared-failure-domain limitation.
- Added Windows edition boundaries for Connection Manager and update policy.
- Added safe PCIe NIC installation, BitLocker readiness, enumeration, restart,
  validation, and rollback gates.
- Separated defaults from historical adapter settings and one-variable
  experiments.
- Added eero radio/noise context and Wi-Fi optimization decision gates.
- Anonymized the eero node labels while preserving the recorded radio
  measurements and no-change decision.
- Clarified that Amy's direct Windows host-failover evidence applies to Windows
  11 Pro; the Home method requires local validation.
- Added documentation-backed, Amy-untested 5/5 and 10/10 stress-test appendices,
  Intel adapter references, motherboard checks, media guidance, and thermal
  gates.
- Added automated PDF QA and full rendered visual verification.
- Added synchronized accessible Markdown companions for all three editions.
- Adopted the same guide/code license split, contribution-only exception, and
  controlled-author publication model used by Amyashi's existing public guide
  repositories.
- Replaced proprietary operating-system font dependencies with PDF Base 14
  Helvetica and Courier aliases for portable public rebuilds.
- Added checksums, citation metadata, security and accessibility policies,
  contribution guidance, community templates, and public-release validation.
- Added clean-checkout QA, semantic-version tag validation, portable rebuild
  instructions, and reproducible full-page visual-review commands.
- Selected
  [`Amyashi/network-performance-resilience-runbooks`](https://github.com/Amyashi/network-performance-resilience-runbooks)
  as the canonical publication target.
